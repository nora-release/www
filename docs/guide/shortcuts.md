# Keyboard shortcuts

Nora's shortcuts for the most common actions. Change the global and chat window shortcuts in **[Settings › Shortcuts](../settings/shortcuts.md)**.

## Global

These work from any app.

| Action | Default |
| --- | --- |
| Open the chat | <kbd>⌘</kbd> <kbd>D</kbd> |

## Chat window

| Action | Shortcut |
| --- | --- |
| New chat | <kbd>⌘</kbd> <kbd>N</kbd> |
| History | <kbd>⌘</kbd> <kbd>H</kbd> |
| Search the conversation | <kbd>⌘</kbd> <kbd>F</kbd> |
| Voice input | <kbd>⌃</kbd> <kbd>M</kbd> |
| Close the window | <kbd>⌘</kbd> <kbd>W</kbd> |

## App

| Action | Shortcut |
| --- | --- |
| Settings | <kbd>⌘</kbd> <kbd>,</kbd> |
| Save a Settings page | <kbd>⌘</kbd> <kbd>S</kbd> |
| Search memories (on the Memory page) | <kbd>⌘</kbd> <kbd>F</kbd> |
| Hide Nora | <kbd>⌘</kbd> <kbd>H</kbd> outside the chat window |
| Quit | <kbd>⌘</kbd> <kbd>Q</kbd> |
