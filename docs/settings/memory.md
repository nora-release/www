# Memory

Control automatic memory and manage everything Nora remembers. See [memory](../features/memory.md) for how memory works.

## Automatic memory

| Setting | What it does |
| --- | --- |
| Automatic memory | When on, Nora remembers useful details from your conversations. It updates memory after a conversation goes idle. |
| Memory activity | Shows what Nora is doing with memory right now, such as finishing cleanup. |

Memories are stored on this Mac and included in conversations when relevant.

## My memories

| Action | How |
| --- | --- |
| Find | **Search memories** (<kbd>⌘</kbd> <kbd>F</kbd>) and **Filters** by **State**, **Source** and **Duration**. |
| Add | **Add Memory**, write it, then **Save**. |
| Edit | Click a memory to change its text and **Tags** (separated by commas). |
| Make temporary | Turn on **Temporary memory**; it is forgotten when it expires. |
| Pause | Turn off **Use in conversations** to keep a memory without using it. |
| Delete | Remove it, then **Save**. |
| Delete everything | **Clear All Memories**, then **Save**. This removes every memory and pending memory task; conversation history is not deleted. |
