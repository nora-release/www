# General

Appearance and how Nora sits on your Mac.

## Appearance

| Setting | Options | What it does |
| --- | --- | --- |
| Appearance | Light, Dark, System | Nora's color scheme. **System** follows macOS. |
| Accent color | Default, Blue, Green, Indigo, Orange, Pink, Purple, Red | The color of selections, buttons and highlights. |
| App icon | Default, Long Hair | The icon in the Dock, menu bar and notch. |

## Conversations

| Setting | Options | What it does |
| --- | --- | --- |
| Diff layout | Unified, Split | How file changes are shown in the timeline. |

## Access to Nora

| Setting | What it does |
| --- | --- |
| Show menu bar icon | Adds Nora to the menu bar for quick access. |
| Show dock icon | Shows Nora in the Dock. Takes effect after you restart Nora. |
| Enable notch control | Shows running tasks and approval requests in the notch on MacBooks that have one. See [notch and menu bar](../features/notch.md). |

## System

| Setting | What it does |
| --- | --- |
| Launch Nora at login | Opens Nora when you log in. macOS may ask you to approve it; click **Approve Nora in Login Items** if it does. |
