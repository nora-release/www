# Access

The macOS permissions Nora can use. Click **Enable** next to one, then **Save** to request it. macOS makes the final decision; **Cancel** changes nothing. **Refresh** rechecks the current state.

| Permission | Needed for |
| --- | --- |
| Screen Recording | Letting the agent see other apps' windows during computer use. |
| Microphone | Voice input. |
| Full Disk Access | Files in protected locations. You may need to add Nora to the list by hand in System Settings. |

**Accessibility**, which [computer use](../features/computer-use.md) needs, is requested the first time the agent operates another app. You can review every permission in **System Settings › Privacy & Security**.
