# Notifications and sounds

## Notifications

| Setting | What it does |
| --- | --- |
| Show scheduled task notifications | Notifies you when a [scheduled task](../features/scheduled-tasks.md) runs. |

## Sounds

| Setting | What it does |
| --- | --- |
| Enable sound effects | Plays sounds for Nora's events. |

Pick a sound for each event and click **Preview** to hear it:

| Event | When it plays |
| --- | --- |
| Agent Task Created | The agent starts a task. |
| Agent Task Complete | The agent finishes a task. |
| Permissions | Nora needs your approval. |
| Schedule | A scheduled task runs. |
| Error | Something went wrong. |
| Copy to Clipboard | You copy something from Nora. |

Sounds include Bloop, Boom, Chime, Clunk, Crack, Ding, Gong, Ping and Plonk.
