# Projects

The folders the agent works in. Each project becomes a group in the sidebar with its conversations under it.

| Action | How |
| --- | --- |
| Add | **Add Project**, choose a folder, then **Save**. |
| Archive | Archive a project to hide it from the sidebar; find it under **Archived** to restore it. |
| Remove | Remove it, then **Save**. Removing a project does not delete its folder or its conversations. |

Changes take effect after you save. See [projects and conversations](../guide/projects.md).
