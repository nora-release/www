# Skills

Three Settings pages manage [skills](../features/skills.md).

## My Skills

Skills you added yourself.

| Section | What it shows |
| --- | --- |
| Custom Skills | Skills you wrote or imported. **Import** adds a skill folder; **Remove** deletes one. Imports and deletions take effect after you save. |
| Imported Skills | Skills brought in from elsewhere. |
| Reflected Skills | Skills Nora found in places it reads automatically. |
| Get More Skills | **Open Skills Folder** to add skills by hand. |

## Built-in Skills

The skills that ship with Nora. Open one to read what it does.

## Synced Skills

Skills from folders you choose, for example a team folder or a Git repository of skills.

| Action | How |
| --- | --- |
| Add a folder | **Add folder**, then **Save**. |
| Refresh | Nora refreshes saved folders when conversations change; **Refresh saved skills** does it now. |
| Remove | **Remove**, then **Save**. |

Nora only adds or removes its own links; your source files stay unchanged.
