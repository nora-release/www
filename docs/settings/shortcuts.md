# Shortcuts

Change Nora's keyboard shortcuts.

| Section | Shortcut | Default |
| --- | --- | --- |
| Global | Open Chat | <kbd>⌘</kbd> <kbd>D</kbd> |
| Chat Window | Voice Input | <kbd>⌃</kbd> <kbd>M</kbd> |

## Change a shortcut

1. Click the shortcut and press the new keys.
2. Click **Save**.

Nora warns you if a shortcut is already used by another Nora action, reserved by macOS, or not allowed. **Clear shortcut** removes one; **Reset to Default** prepares the defaults, which apply when you save.

See [keyboard shortcuts](../guide/shortcuts.md) for every shortcut in Nora.
