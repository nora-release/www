# About

Version information and maintenance.

| Setting or action | What it does |
| --- | --- |
| Version | The installed version of Nora. |
| Check for Updates | Looks for a new version now. |
| Auto check for updates | Checks for new versions on its own. |
| Update plugins automatically | Keeps plugins from Nora's official sources up to date. See [trust and updates](../plugins/trust.md). |
| Install nora Command | Links the `nora` command into `~/.local/bin`. See [installation](../guide/installation.md#install-the-command-line). |
| Log Viewer | Shows Nora's logs, useful for bug reports. |
| Reveal Application Directory | Opens Nora's data folder in Finder. |
| Reset Settings and Memory | Resets Nora's settings and long-term memory after you save. Conversation history is not deleted. |
