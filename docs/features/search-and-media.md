# Search, images and video

Some providers offer built-in tools for searching and generating media. Nora turns them on for the agent when your model supports them.

## Online search

Turn on **Web search** and **X search** in **[Settings › Tools › Online Search](../settings/tools.md)**.

- Search runs through the selected model's provider and may count toward that provider's usage.
- Web search and X search are available only when the model supports them.

## Image and video generation

When one of your providers offers image or video models, the agent gets generation tools. Choose the **Default Image Model** and **Default Video Model** in **Settings › Tools**.

If none of your providers support generation, the Tools page says **No generation tools available**. Add a provider that does in **[AI Providers](../providers/)**.
