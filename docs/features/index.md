# Features overview

What Nora's agent can do, and the features that shape how it works.

## Core features

| Feature | In one line |
| --- | --- |
| [Tools and permissions](./tools.md) | The agent reads, edits, runs commands and searches on your Mac. |
| [Plan mode](./plan-mode.md) | Research and a written plan first; changes only after you approve. |
| [Goals](./goals.md) | An objective the agent keeps working toward across turns. |
| [Memory](./memory.md) | Notes about you and your projects that Nora brings back when they matter. |
| [Side panels](./side-panels.md) | A terminal, files, Git and a browser next to the conversation. |

## Advanced features

| Feature | In one line |
| --- | --- |
| [Skills](./skills.md) | Reusable instructions the agent loads when a task calls for them. |
| [MCP servers](./mcp.md) | Tools from other programs and services, with per-tool access. |
| [Scheduled tasks](./scheduled-tasks.md) | Work that runs later, once or on a repeat. |
| [Computer use](./computer-use.md) | The agent operates apps that have no command line. |
| [Search, images and video](./search-and-media.md) | Web and X search, image and video generation through your providers. |
| [Notch and menu bar](./notch.md) | Follow running tasks and approve requests without opening the window. |
