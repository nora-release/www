# Side panels

The toolbar on the right edge of the chat window opens panels next to the conversation, so you can check the agent's work without switching apps.

| Panel | What you can do |
| --- | --- |
| Terminal | A full terminal in the project's folder. Run anything; the agent's terminal sessions show up here too. |
| Files | Browse the project, preview files and reveal them in Finder. |
| Git | See changed files and diffs, stage or unstage everything, and fetch, pull or push. |
| Browser | Open pages the agent links to, or anything else, beside the conversation. |

Panels belong to the conversation's project. Open a panel in a larger window from its **More** menu.
